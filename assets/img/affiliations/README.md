# University emblems

These images identify the universities in the personal homepage's affiliation section. Each image links to the respective university homepage. The images were downloaded without alteration on 2026-10-13.

For the homepage preview, the `affiliation-mark` SVG filter removes white from the rendered marks and applies the interface foreground color. This unifies them with the contact icons on light, dark, and wallpaper backgrounds. The downloaded source files remain unchanged.

- `scut.png`: South China University of Technology emblem from the university's [official identity page](https://www.scut.edu.cn/new/9017/list.htm). [Original PNG](https://www.scut.edu.cn/_upload/article/images/16/02/3166fd1b4c8cb0148ec56c04f071/c6faf181-ecc2-4b0b-b05d-1f4c04780ce6.png).
- `hkust-gz.png`: emblem used as the 192px site icon by the [HKUST(GZ) official homepage](https://www.hkust-gz.edu.cn/). [Original PNG](https://material.hkust-gz.edu.cn/wp-content/uploads/2023/04/cropped-favicon-1-1-192x192.png).

The marks and associated rights belong to their respective universities. They are not covered by this repository's code license. Display here describes the author's affiliations and does not imply that this personal website is an official university website.
